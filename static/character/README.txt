ここにキャラクターの表情画像を置いてください（PNG推奨・背景透過）。

  normal.png     通常
  happy.png      うれしい（提案・褒められたとき）
  thinking.png   考え中（返事を待っているとき）
  surprised.png  驚き（賞味期限が近い食材を見つけたとき）
  troubled.png   困った（食材が足りない・エラーのとき）

画像が無い表情は normal.png に、normal.png も無ければ絵文字で代用されます。
表情の種類を増やす場合は gemini.py の CHARACTER["expressions"] に名前を追加し、
同じ名前の画像を置いてください。
